# Manuscript figure files

`Figures English/` contains **all eight manuscript figures**: Figure 1 (PRISMA, editable PowerPoint and TIFF), Figures 2–5, and Figures S1–S3. **Figures S1, S2 and S3 are present in PNG and TIFF**; S2 presents diagnostic methods and S3 presents data availability. The R-generated PNG/TIFF files are retained as **1,200-dpi master exports**; the corresponding analyses are in `../scripts/`. The figure files were provided with the repository and were not regenerated by this documentation update.

Do not overwrite master figures when preparing submission-sized copies for *PLOS ONE*. The Spanish figures and their scripts are in `../Español_Spanish/`.
