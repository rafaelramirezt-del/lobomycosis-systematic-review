# English R scripts

Seven complete English scripts reproduce Figures 2–5 and S1–S3. Open a `.R` file in RStudio, run **Source**, and select `../data/raw/Lobomycosis_database_EN.xlsx` using the `file.choose()` dialog. Each script produces PNG, TIFF, a CSV summary and a one-sheet Excel audit **in this directory**. Existing files are not overwritten. Figure 1 (PRISMA) is an editable PowerPoint, not an R analysis.

See [`../README.md`](../README.md) for the figure inventory and caveats. The Spanish counterparts are in [`../Español_Spanish/`](../Espa%C3%B1ol_Spanish/LEEME.md).
